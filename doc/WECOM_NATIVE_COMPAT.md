# 原生文本接口兼容验证（2026-10-21）

已适配 Windows x86 企业微信 5.0.11.6029 和 5.0.12.6018。
按运行进程可执行文件 SHA-256 选择独立配置，继续核验入口、服务虚表、登录账号和已有单聊。
不按版本字符串直接放行，也不把旧地址用于未知更新。

新版验证证据：

- 腾讯签名有效的官方 5.0.12.6018 安装包，与本机更新后的 WXWork.exe 哈希一致。
- 八个入口的旧 RVA 均不再有效；重新定位后，控制流可达指令的对比未发现除地址外的差异。
- 下层 MessageServiceImpl 发送方法新增分支，因此不能宣称所有后续版本均通用。
- 只读核验了新版服务对象、虚表和账号链；中英文测试对象构造、解析及释放通过。
- 空消息调用被拒绝，返回无效编号，没有提交消息。
- 经用户明确确认收件人和正文，仅发送一次测试消息；原生编号、同一会话、发送人、完整正文、服务器编号与序列号全部核对成功。约 1.4 秒完成。
- 17 项原生回归测试及 22 项进程发现测试通过；模拟测试没有发送真实消息。

打包运行环境修复：已确认原版 psutil 在该运行环境导入时改变进程令牌中的调试权限状态，随后原生连接报 TransportError。使用哈希校验的 psutil 5.9.6 官方源码重建，仅移除导入时自动调整权限的调用，保留调用方原有权限。构建脚本为 desktop/psutil_runtime.py，分发包附上游许可证与修改来源说明。
已增加窗口所属进程交叉检测，补充进程枚举遗漏，并区分版本不匹配与连接失败。
修正后的安装包自带 Python 已完成新版企微连接及登录账号校验；该检查没有发送消息。未来未经验证的二进制仍不会套用旧地址。

详细静态和运行记录仅存放在 reports/private/wecom-native-5.0.12.6018，不进入分发包。
